📊 ARCHITECTURE
================================================================================

COMPONENT HIERARCHY:
  HeroSection (responsive wrapper)
    ├── MobileHero (<768px)
    │   ├── Badge (animated pulse)
    │   ├── Title (text-3xl bold)
    │   ├── Description (text-sm)
    │   ├── Primary CTA (full width, orange)
    │   ├── Secondary CTA (optional)
    │   └── Background (pan animation)
    └── DesktopHero (≥768px)
        ├── Carousel (3 slides, auto-rotate)
        ├── Navigation (arrows + dots)
        ├── Left Copy (badge, title, subtitle, CTAs, trust)
        ├── Right Card (product preview, badges)
        └── Floating Shapes (decorations)

BREAKPOINT LOGIC:
  Mobile:   window.innerWidth < 768px   → <MobileHero />
  Desktop:  window.innerWidth ≥ 768px   → <DesktopHero />
  SSR:      Defaults to <DesktopHero /> (safe fallback)
  Resize:   Re-evaluates on window resize event

ANIMATION FLOW:
  Mount
    ↓
  Staggered container animation (delayChildren: 0.2s)
    ↓
  Badge animates (0ms → 200ms)
  Title animates (100ms → 300ms)
  Description animates (200ms → 400ms)
  CTAs animate (300ms → 500ms)
    ↓
  All elements visible (complete in 500ms)
